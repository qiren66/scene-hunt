# SceneHunt - 场景猎手 🎬

> 带着电影去旅行 — 影视取景地打卡平台

## 产品简介

SceneHunt 是一个融合"片场"级专业数据库与 anitabi 式 UGC 社区生态的影视取景地打卡平台。用户可以搜索影视作品、在地图上查看取景地、使用场景复现工具拍出电影同款照片。

## 核心功能（MVP）

- 🔍 **全局搜索**：按剧名、地名、演员名搜索取景地
- 🎬 **作品详情**：查看作品信息、名场面列表、剧情简介
- 🗺️ **取景地地图**：在地图上标注所有取景地，支持筛选
- 🖼️ **场景复现工具**：上下/左右对比图 + 透明叠影模式
- 📸 **叠影相机**：半透明剧照叠加实时相机画面，拍出同款机位照片
- ❤️ **本地收藏**：标记"想去"和"已打卡"，数据存储在本地

## 页面结构

```
搜索首页 (/) → 作品详情页 (/work/:id) → 地图页 (/map/:workId)
                                      → 取景地详情页 (/location/:id)
```

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 地图配置

使用高德地图需要申请 API Key：

1. 前往 [高德开放平台](https://lbs.amap.com/) 注册账号
2. 创建应用，获取 Web端 JS API Key
3. 修改 `src/utils/map.ts` 中的 `key` 参数

> 不配置地图 Key 也能正常使用，地图页会降级为坐标列表模式。

## 设计风格

- **配色**：电影胶片质感（黑金风）
  - 主背景：`#0D0D0D`
  - 卡片背景：`#1A1A2E`
  - 金色强调：`#D4AF37`
  - 暗红辅助：`#8B0000`
- **加载动画**：场记板打板动作
- **交互反馈**：卡片点击缩放 + 按钮触感
